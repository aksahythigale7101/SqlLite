SQLAlchemy : SQLAlchemy is a Python library used to communicate with databases.
           :SQLAlchemy ORM वापरल्यावर Python मध्ये आपण database table ला Python class/object म्हणून work करू शकतो.
     SQLAlchemy = Python आणि Database यांच्या मधला bridge.   
                  +-----------------------------------------------+
                  | Python Code---->SQLAlchemy--->SQLite Database |
                  +-----------------------------------------------+        
ORM(Object Relational Mapping): ORM त्या Python object ला database row शी map करते.  म्हणूनच त्याला Object Relational Mapping म्हणतात.                                  
                 PYTHON CLASS TO DATABASE TABLE MAPPING
                              :Python मधल्या objects/classes ला database मधल्या tables सोबत जोडण्याची पद्धत म्हणजे ORM.
                 ======================================
                 [Python Student Class]  --------->  [Database 'students' Table]
                 ---------------------------------------------------------------
                 Student object          --------->  One single row in the table
                 id attribute            --------->  id column (INTEGER PRIMARY KEY)
                 name attribute          --------->  name column (TEXT)
                 age attribute           --------->  age column (INTEGER)

         :Engine हा SQLAlchemy आणि SQLite database मधला bridge आहे.

5.Model म्हणजे काय?:SQLAlchemy ORM मध्ये आपण हा table Python class म्हणून define करू.

                 :Model म्हणजे database मधल्या table चे Python representation.
                 :A Model is a Python class that represents a database table.
6.Base: SQLAlchemy ORM models साठी base class.
      :Base is the parent class for our SQLAlchemy models.

execute():हे SQLAlchemy Result object देते.पण आपल्याला wrapper Row नको आहे.execute() Multiple Columns साठी(Example stmt = select(Student.name, Student.age)---result = session.execute(stmt)).
         :execute() फक्त ORM Student objects साठी नाही.जेव्हा आपण multiple columns select करतो तेव्हा ते खूप useful आहे
scalars(): by using scalars() method,we get the call object  (example-->students = session.scalars(stmt).all())or(stmt = select(Student).where(Student.id == 5))
--इथे scalars() वापरल्यास फक्त पहिला selected column (name) मिळेल. त्यामुळे multiple selected columns असताना execute() समजून घेणे महत्त्वाचे आहे.      
     Method	                Output
     session.execute(stmt)	Row (tuple) → ro[0].name लागतं
     session.scalars(stmt)	थेट object → ro.name चालतं 
     session.query(stmt)     थेट object → ro.name चालतं(old style)

Code	                   काय मिळतं?
session.execute(stmt)   →  Result
result.first()          →  First Row
result.all()	        →  All Rows
result.scalars()	    →  Scalar values / ORM entities / Row मधून actual value/object
result.scalars().all()  →  List of scalar values / ORM objects
session.scalar(stmt)	→  Single scalar value / ORM object
result.first()          →  पहिला result
result.one()            →  exactly one result

ForeignKey :It references a key in another table and helps enforce referential integrity.
relationship():It defines an ORM-level relationship between mapped Python objects.
      --->ForeignKey हा database-level connection आहे आणि relationship() हा ORM/Python-level connection आहे.
  *_______________________________________________________________________________________________________________________*
  |ForeignKey     →  Database level,Database connection,Uses column,department_id ,References another table               |
  |relationship() →  ORM/Python level,Python object connection,Uses Python attribute,department,Provides object navigation|
  |back_populates()→ Connects both ORM relationship properties                                                            |
  *_______________________________________________________________________________________________________________________*
back_populates():It connects the two sides of a bidirectional ORM relationship.
                :back_populates दोन models मधील relationship च्या दोन्ही sides ला एकमेकांशी connect करते.

⭐ N+1 Query Problem: N+1 Query Problem avoid करणे खूप important आहे.
                    :एक query parent records साठी आणि प्रत्येक parent साठी एक additional query related records साठी चालल्यामुळे 1 + N queries होतात. याला N+1 Query Problem म्हणतात.
Lazy Loading :जेव्हा related data ची गरज पडते तेव्हाच database query चालते, त्याला Lazy Loading म्हणतात. 
Eager Loading :आपल्याला related data आधीच माहिती आहे की लागणार आहे, तर main data सोबत related data सुद्धा आधीच fetch करणे म्हणजे Eager Loading.
Eager Methods  1.joinedload() :related table ला JOIN करून data load करण्यासाठी वापरतो.
             :joinedload() collection relationship (one-to-many) सोबत वापरताना SQLAlchemy मध्ये unique() आवश्यक असू शकते/लागते कारण JOIN मुळे parent rows duplicate होतात.

Q: SQLAlchemy ORM आणि Core मध्ये फरक काय?
SQLAlchemy ORM provides an object-oriented way to work with database tables using Python classes and objects, 
                      while SQLAlchemy Core provides a lower-level SQL expression and table-oriented interface
                      with more direct control over SQL operations.
                     :ORM मध्ये Python classes आणि objects वापरून database शी काम करतो, तर Core मध्ये tables
                      आणि SQL expressions वापरून database शी अधिक direct पद्धतीने काम करतो.
